
# Piano Trainer

**Live Demo:** https://asharaya.github.io/Piano-Trainer/

Aan interactive piano game developed with HTML, CSS, and JavaScript. Education purposes only.

## Features

- Interactive piano with 17 keys.
- Play notes using your keyboard or mouse.
- Three songs with different difficulty levels.
- Falling notes synchronized with each song.
- Score tracking and progress indicator.
- Free Play mode.
- Responsive design for different screen sizes.

## Songs

- Twinkle Twinkle Little Star
- Ode to Joy
- Für Elise

## Technologies

- HTML5
- CSS3
- JavaScript
- Web Audio API

## How to Play

1. Open the live demo.
2. Select a song or Free Play mode.
3. Press the corresponding piano keys.
4. Follow the falling notes and complete the song.
5. View your results and try again!
